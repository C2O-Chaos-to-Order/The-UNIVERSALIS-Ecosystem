# Requirement trace

Identifiers are `ULC-<tablet>-<clause>`. They are not the collection-level `UNI-001`…`UNI-015` map, which is a different register and is not implemented here.

A line that names a test means the test exercises the behaviour. It does not mean the requirement is accepted, reviewed, or complete. Thirty-one identifiers are not implemented. P4 has no close list. P5 closes only ULC-21-07. P6 closes only ULC-21-01, ULC-21-03, and ULC-21-09. P7 closes only ULC-00-11, ULC-00-12 (partial), ULC-16-05, ULC-16-11, ULC-26-03, and ULC-26-05.
